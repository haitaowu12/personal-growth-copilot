## Per-participant record fields

Pseudonymous ID; consent version/date; experience/domain/language context;
accommodations; form allocation; baseline start/end; learning start/end (delayed
window anchor); active/elapsed minutes, pauses/breaks and reasons for every phase;
early stopping; actual concept routes; source,
hint, worked-example and writing-example exposure, repetitions and substantive-help
use; confirmation that writing criteria were visible before drafting; self-review
completion (learner judgment, not a grade); identical public rubric visible at each
outcome; immediate start/end; delayed scheduled/start/end timestamps with UTC offset;
hours from learning end to delayed start; intervening practice; prior day-seven
review/explanation exposure; procedural/reading/motor/translation/conceptual/uncertain
help and adjudication; overlapping assisted, exposed, uncertain, early and late flags;
complete/incomplete assessable artifact versus received nonresponse versus missing
artifact at each timepoint; withdrawal/missingness reason where volunteered; de-identified
artifact references; separate original scorer ratings per criterion and reasons;
adjudication and any timepoint unblinding; confidence/effort and observed friction;
actual facilitator/custodian/scorer effort. No identifiable data belongs
in the release package or implementation repository.

Record enrolled, received, assessable and analysis-subset denominators for each
timepoint, plus flag intersections. An incomplete substantive attempt is assessable;
an omitted elicited criterion may score zero. A missing artifact, blank/nonresponse
or refusal receives no artifact-level score. Neither is silently counted as success.
Confirm de-identification of every historical write and other identifying field
before any authorized history transfer; use separate minimized scoring artifacts.
