# Consolidated portable agent skill

Implementation subject: `mac/consolidated-agent-skill`, based on Copilot
`08fcbec7888a7a6ff37bdb41cfb0b8bbcb68347d`, with Interpersonal Strategist
`224c8af74bd3558ac6b0af810dde6078fe16105c` and the existing portable leadership
integration `91ad9e600cf9490e407a692ee49faefc9fee0b78`. The source library's
twelve card versions are carried in the runtime method index. No new application,
live notebook, MCP service or second invoked skill is required.

## Use the skill

Invoke `$personal-growth-copilot` explicitly in a compatible agent host. The
existing identifier is retained for compatibility; it now routes to the complete
growth, interpersonal, leadership and learning capability set. Examples:

- “Help me understand a recurring pattern and choose a small experiment.”
- “Interview me before advising about a disagreement with my sibling.”
- “Help me decline a housemate's request without inventing an excuse.”
- “Use Chinese to clarify whether that message acknowledged receipt or agreed.”
- “Help me prepare an honest dating invitation with room to decline.”
- “Help me discuss our relationship expectations; don't infer consent.”
- “Teach me delegation, then rehearse the conversation one turn at a time.”
- “Help me choose a strategic focus and what must stop to make room.”
- “Use the decision-fit helper on my supplied criteria, showing unknowns first.”
- “Teach me requirements writing using the offline lesson.”

Ask for a quick answer, explanation, interview, rehearsal, review or portable
summary as needed. The skill uses the request and current context; it does not
require a product/mode menu or introduce a score/profile in every conversation.

## Portability and installation boundary

The complete Agent Skill folder contains its entry, specialist references,
necessary assets and helpers. The portable bundle also includes the independent
requirements-writing HTML and acceptance/pilot documents. Build with the declared
locked development environment and `scripts/package_learning.py`; install the
extracted skill using the intended host's own supported explicit-skill workflow.
This repository does not claim that a host was installed or configured by a build.
No new background process, account or connector is needed for conversation.

The existing plugin is an optional delivery wrapper. The published installation
tag remains older; this local candidate is identified by its commit/package,
not by a newly published tag. Keep installed versions and prior bundles available
for recovery. No installed skill, old source repository or service is replaced
by creating this candidate.

## Consolidated ownership

The entry selects a capability. Shared inquiry owns readiness, ask/wait, bounded
challenge, correction and stopping. One rehearsal reference owns setup/scene/
debrief and drills; shared reflection owns actual-outcome review. Interpersonal
modules retain work, friendship, family, household, romance, partnership,
separation, negotiation, multi-actor, bilingual, digital/AI and source-lens
knowledge. Leadership retains all twelve methods and seven guide routes.
Teaching retains its attempts, help exposure, feedback and transfer boundaries.

The optional score helper is byte-retained from the status-first `0.13` donor.
Source-specific interpersonal evidence IDs are namespaced; they do not become
valid growth-record citations without an explicit supported mapping. Rehearsal
and actual-world evidence remain distinct. Portable leadership cards omit private
motivating context and raw source files while retaining method conditions and
book/edition locators from the inspected source syntheses.

## Records and permissions

Session-only remains the default. No database, automatic case memory, profile
collection, persistence adapter, hidden person model or blanket AUTO_UPDATE is
enabled. The existing exact-preview/host-attestation and safety controls remain
authoritative. A requested dossier/card is user-inspectable, minimal, bounded,
correctable and expirable; unsupported operations stay unconfirmed. A calculator
output file is not a memory write. No capsule is automatically created or loaded.
Skill memory controls do not erase provider chat histories, logs or backups.

The original sources' dirty persistence work is preserved outside this candidate.
Browser progress, growth records and relationship case content are not silently
merged. No automatic send, assignment, reminder, schedule or external lookup is
implied by method wording.
