# Capability and ownership map

One explicitly invoked skill loads the relevant module. No second product or
live notebook is required. These are implemented instruction/package capabilities;
independent model/host/human outcomes are separate evidence gates.

No auto-dossiers, standalone non-user profiles, manipulation, clinical/legal/HR adjudication,
score-driven coercion or implicit external actions are added. Optional persistence
still needs actual verified host capabilities; the bundled store is non-persistent.
The older standalone products are recovery/compatibility sources, not runtime
dependencies. Existing qualification receipts do not become evidence for this
combined instruction subject merely because their software controls are reused.
