# Changelog

## 0.5.0-alpha.1 — engineering candidate

### Added

- Governed five-system evaluation contract for target, direct assistant,
  structured reflection, strong generalist, and minimal visible model.
- Twelve ordinary-growth, multi-session, correction, recovery, non-action,
  tracking-burden, family-pressure, and low-engagement cases, bringing the
  authored suite to 25 cases, 106 turn nodes, 49 entry variants, and 610 planned
  synthetic run identities.
- Governed technique registry with eight candidate techniques, explicit
  eligibility, contraindications, burden, expected and disconfirming signals,
  review windows, alternatives, and evidence-source mappings.
- Descriptive paired strong-comparator campaign outputs with benefit claims
  fixed off.
- Reproducible packaged learning candidate and automated file-origin browser
  acceptance for the complete journey, persistence controls, imports, storage
  denial, offline execution, reduced motion, and narrow layout.

### Changed

- Provider protocol upgraded to `pgc-stdio-v3` with system-contract,
  system-profile, and profile-bundle hashes.
- Target configuration, run, result, campaign, attempt, and release schemas now
  require all five governed systems.
- Campaign and bilingual-review aggregation now derive their system set from the
  governed contract.
- Outcome documentation distinguishes executable comparator slots from still
  unexecuted behavioral and user-outcome evidence.
- Action selection now consults the governed technique registry and preserves
  intentional non-action when no technique fits.

### Fixed

- Provider profile loading now canonicalizes macOS `/var` and `/private/var`
  paths before enforcing repository containment.
- Test fixtures, reviewer evidence, campaign counts, and qualification language
  no longer assume a three-system or stdio-v2 contract.

### Qualification boundary

Engineering controls and local packaged-file browser acceptance are implemented.
Real model execution, human review, holdouts, named-host privacy, controlled
pilots, learner outcomes, independent release review, and owner promotion remain
separate blocked gates.
